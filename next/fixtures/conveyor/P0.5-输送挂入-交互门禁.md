## 人话条（接入后 vs 仍拒跑 · 继承藏四卡）

| 态 | 人话条（可粘贴） | 主四卡 |
|---|---|---|
| **接入后 · 跑通**（仅直线三件 + 接驳齐 + 默参） | 无拒跑条；状态可读「已推演」 | **露出**有限数（禁 NaN / 禁「—」充数） |
| **仍拒跑 · 未接类型**（弯道/合流/分流/缓冲/垂直等本刀未接） | **「本切片暂不仿真该类」** + `elementId` | **完全不露**；禁空「—」壳 |
| **接驳失败 / 断链** | **「输送还没接上：把端口对到邻段或月台后再推演」**（可附未接端口侧设备名） | **不露**；禁假绿四卡 |
| **缺必填参**（默认被清空等） | **「还差必填参数才能推演」** + 人话列缺项名（如速度、长度） | **不露** |
| **未点推演 / 未跑** | 灰态 **「未推演」** | **不露**（PR#5） |
| **规范硬冲突挡推** | 既有约束人话红灯（≤2 步修复） | **不露**直至硬=0 |

统一禁：假 KPI、空「—」四卡壳、静默失败。

## 关键步数上限（对齐 UA B2）

| 路径 | 上限 | 口径 |
|---|---|---|
| **主路径**（放 ≥1 段直线 CV 用默参 → 保存 → 准备 → 推演 → 见主四卡） | **bot 有效步数 ≤12** | 从空/样例仓起算可点操作；不含纯滚轮浏览 |
| **接驳失败修复** | **≤2 步** | 点人话条 → 拖齐 ports → 可再点推演（继承 D3） |
| **缺参修复** | **≤2 步** | 点人话缺项 → 填回默认/改值 → 可再推 |
| **改参过期** | **≤1 步** | 黄条「一键重跑」（五刀既有） |

## 可粘贴验收句（给 UA / 编码）
1. 仅 `CV-STR-01`（或 ROL/BELT）+ 接驳齐 + 默参 → 推演 **不再**出「本切片暂不仿真该类」→ `data-decision-cards=shown` 且四卡有限数；主路径 ≤12 步。
2. 同布局再放 `CV-CURVE-01`（或 MERGE/DIV/BUF）→ 推演人话「本切片暂不仿真该类」+ 该 ID → **不见四卡/「—」**。
3. 故意断链直线段 → 人话「输送还没接上…」→ 藏四卡；对齐 ports ≤2 步后可跑通。
4. 未点推演 → 仅灰态「未推演」，无空壳四卡。
