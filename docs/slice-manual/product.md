# 产品说明 · 人工摆放切片

主路径：从空白场地或矩形模板放下 `ST-PAL-01`、`IN-DOCK-01`、`OUT-DOCK-01`，用米改位置，撤销一步，保存得到服务端修订，准备，再推演。四张卡只显示这一次运行返回的数。

工作台壳对齐所附原型的分区：顶栏（项目、布局编辑 / 决策视图、撤销、重做、保存）、左元素库、中画布、右参数与校核、底状态条、决策页四卡与回放。视觉用原型的浅底青绿。原型里的演示计算不进入本切片。

## P0 画布（2026-10-29 批准）

首屏打开 `template.mixed_wh_v0`，综合仓主路径设备已按米摆好。摆放从元素库拖入，松手前显示占地幽灵和绿 / 黄 / 红。画布用批准的浅底青绿，缩放不改变占地米数。决策页按本次运行的轨迹段插值回放。矩形模板和空白场地仍可切换；两者都不预放设备，也不预填日出量、速度或处理时间。空白场地带默认场地和通道尺寸。
